## 1. 项目结构

```
mdm-customer/
├── component.yaml            # 平台读的那份

│   ├── customer.proto        # gRPC 契约
│   ├── customer.openapi.yaml # HTTP 契约（对外 REST）
│   └── events/
│       └── customer.events.json
├── backend/
│   ├── module/module.go      # 唯一入口 New(ctx, rt)
│   ├── cmd/server/main.go    # 一行 besdk.RunStandalone(module.New)
│   └── internal/...
├── migrations/
│   ├── 001_xxx.up.sql
│   └── 001_xxx.down.sql
├── Dockerfile
├── Makefile
└── README.md
```
